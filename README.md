# ccoinclicker - TP2 Cookie Clicker

##  Installation & run

1. Clone the repository:
   git clone https://github.com/ccao94/ccoinclicker.git 
   -> cd ccoinclicker (then unzip TP2.zip)
   -> cd TP2
   
2. Install dependencies :
npm install

3. Start the development server :
npm run dev

4. Open the app in your browser :
http://localhost:5173
